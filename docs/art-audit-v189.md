# v188 → v189 怪物美术审查

## 基线与发现

GitHub main 基线为 `9782c8546370f11feb8693068f3854ae73e0b1c1`，用户随后明确指定上传的 v188 为最新版本，因此本次使用上传文件的活动入口 `index.html` → `game.js`。包内 game-v184/185/186/187.js 没有被入口引用，不作为基线。

原 atlas 为 640×640，8×8 格，每格 80×80。游戏共 58 种怪物。v188 中 sprite() 使用物种 ID 定位 atlas，但配色 profile 部分使用 spriteBase，不能确保 profile 对应实际那一格的解剖区域。配色实际仍是 radial-gradient 遮罩与滤镜叠加，不是像素级分区。后加的两段动画定义缺少 @keyframes。多套闪光 CSS 与移动动画互相覆盖。

上传与仓库中的 atlas 相同，第五个 IDAT 数据块 CRC 错误，标准 PNG 解码失败；容错解码只能读出上部约五行，不能把这个残缺图当作完整资源继续发布。v189 的 PNG 从索引源稿重新编译，全部可完整解码。

## 方案比较

| 方案 | 适合情况 | 本项目判断 |
| --- | --- | --- |
| 分层 PNG | 大量可组合装备和部位 | 可以准确分区，但每只多层对齐、缩放、界面覆盖更复杂 |
| 运行时 palette swap | 动态且无限的调色 | 需要像素读取、画布缓存和异步加载，文件直开与浏览器兼容更复杂 |
| 预生成多色 atlas | 有限且固定的颜色槽 | 采用：现有 6 普通 + 3 限定色，保持原 8×8 寻址，只切贴图，无运行时染色 |

制作阶段仍使用真正的索引调色板。像素角色 a/b/c/d 为可变色明暗，其余角色为固定色或透明。运行时使用已编译 atlas；所有格子对齐、alpha 一致。

## 明确区域

- 苗芽团：叶、芽、茎变色；米白身体、脸、眼和描边固定。
- 焰角仔：红色头、身体、四肢、尾变色；浅色腹部、角、眼和描边固定。
- 潮鳍獭：蓝色毛区与鳍变色；脸腹浅色、眼、亮纹和描边固定。
- 月影狐：两侧耳外、头顶、躯干、四肢与整段深色尾巴均归入可变色；脸部浅色、尾部亮纹和描边固定。不是半边或尾端局部遮罩。
- 其余种族的明确区域见 art/sprites.json 的 variableRegion / fixedRegion；派遣种族有独立像素格，不再套基础模型的猜测遮罩。

## 集成与兼容

sprite() 是所有个体显示的唯一入口，返回物种、颜色数据属性供检查，并统一插入独立 shiny-fx 子层。粒子动画不会覆盖父级走路/呼吸动画。减少动态效果模式保留静态星芒与光晕。

原存档 key、版本 9、58 个种族 ID、普通 tint 0–5 与限定 specialColor 0–2 保持不变。没有清空、迁移或重置旧存档。游戏入口与 atlas URL 带 v189 缓存版本。v188 的玩法变化完整保留，未从仓库的旧玩法回退。
