# Qinster 牧场 v197

以用户提供的 **Qinster-Ranch-GitHub-v188(1).zip** 中 `game.js`、`index.html` 为玩法基线，更新怪物美术与配色。

- 58 个原创、确认版长豆豆眼模型（128px 单格）：18 个基础种族 + 40 个派遣限定种族。
- 9 套预生成 atlas：原色、薄荷、绯红、月蓝、紫晶、金辉、极光、琉璃、夜曜。
- 原生索引像素源稿明确标记固定色和可变色，不使用整只滤镜或近似 CSS 遮罩。
- 牧场、怪物盒、亲代 A/B、派遣、图鉴和孵化弹窗共用同一个渲染函数与闪光粒子层。
- 存档仍为 `eggwood-monsters-v3`，物种 ID、tint、specialColor、shiny 语义不变。
- 保留 v188 的配种、生命、家族、商店与派遣规则。

## 运行

GitHub Pages 直接使用根目录 `index.html`。不需要打包；`assets/` 必须一起提交。
本地开发：`npm ci`，然后 `npm run dev`。Vite 只用于本地预览，不是游戏运行依赖。

## 美术维护

`art/source/approved-bean-eyes.png` 为确认版原稿，`monsters-original.png` 为透明源图，`variable-regions.png` 为明确的逐像素变色区域图。
安装 `scripts/requirements-art.txt` 的依赖后，`npm run art` 从透明源图与区域图生成全部 atlas。普通构建不重新推断颜色区域。

`art/review.html` 是全部 58 × 9 配色的审查表。
`npm test` 检查所有物种、颜色与闪光渲染组合。
构建脚本还逐像素验证固定区域在所有颜色中完全不变。
详见 [审查与方案](docs/art-audit-v189.md)。

仓库内 v169 ZIP 仅为历史附件，不是游戏入口；不要用它覆盖当前源码。

## v197 场景与桌面派遣旅伴

牧场增加分层天空、远山、树木、木栅栏、草地与小路；八种派遣地点共用可缩放的像素景色。移除牧场内重复的派遣走动队列，保留独立派遣小窗。

点击「桌面悬浮」可在支持 Document Picture-in-Picture 的桌面浏览器中打开置顶小窗，无需安装 App。必须手动点击；关闭游戏标签页会同时关闭悬浮窗。不支持时继续使用页内窗口。悬浮窗仅展示现有派遣状态，不参与结算、不写存档；到达后返回游戏领取。

验证：JavaScript 语法及模拟画中画生命周期检查通过，包括窗口打开、同步、到达、空队伍及关闭清理。本次环境没有浏览器，背景视觉与真实浏览器最小化行为尚未实测。
