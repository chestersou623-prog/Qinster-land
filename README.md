# Qinster 牧场

Qinster 牧场是一款怪物育种、派遣、孵蛋与牧场养成网页游戏。

## 在线部署

本仓库可直接使用 GitHub Pages：

1. 上传仓库全部文件到 GitHub。
2. 打开仓库 **Settings → Pages**。
3. 在 **Build and deployment** 选择 **Deploy from a branch**。
4. Branch 选择 `main`，Folder 选择 `/ (root)`，然后 Save。
5. 等待 GitHub Pages 完成部署后即可通过网页打开。

## 文件

- `index.html` — 游戏页面
- `game.js` — 游戏逻辑
- `monster-atlas.png` — 怪物图像资源

## 当前版本

基于 Qinster v150。
